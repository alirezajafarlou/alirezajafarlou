## Projects

### [Health API](https://github.com/alirezajafarlou/health-api)

A small Node.js REST API built as a practical introduction to containerization and CI/CD.

**Highlights:**

* Node.js REST API with health-check endpoints
* Automated endpoint testing with Jest
* Dockerized with Docker and Docker Compose
* Optimized production Docker image using `node:24-bookworm-slim`
* Production image excludes development dependencies
* GitHub Actions CI pipeline
* Automated Docker image publishing to GHCR
* Docker image optimized from approximately **1.7 GB to 410 MB**

**Stack:** `Node.js` · `Express` · `Jest` · `Docker` · `Docker Compose` · `GitHub Actions` · `GHCR`
